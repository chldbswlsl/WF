Project

Rust Compiler

1. 바꾸고 싶은 Rust 코드를 src 안에 문자열로 집어 넣는다.
2. lexer가 코드를 TOKEN 단위로 쪼갠다.
3. parser가 토큰을 문법에 맞는 AST로 만든다.
4. codegen이 AST를 실제 실행 가능한 기계어로 변환한다.
5. 출력한다.

Emotion Analysis AI

1. 감정을 분석하고 싶은 문장을 입력한다.
2. 입력된 문장을 정리하고 숫자로 변환한다.
3. 크롤링으로 학습된 인공지능 모델이 문장을 분석한다.
4. 숫자로 표현된 예측 결과를 실제 감정 이름으로 바꾼다.
5. 예측된 결과를 화면에 보여준다.
